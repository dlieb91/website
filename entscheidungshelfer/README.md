# Entscheidungshelfer

Web-App für strukturierte Entscheidungen anhand einer gewichteten Kriterien-Matrix: Optionen (z. B. Jobangebote, Wohnungen) und Kriterien (z. B. Gehalt, Lage) anlegen, Gewichtungen vergeben, jede Option pro Kriterium bewerten – die App berechnet daraus ein Ranking mit Score.

Start: `index.html` im Browser öffnen (Doppelklick oder z. B. mit `python3 -m http.server` lokal servieren).

Funktioniert vollständig offline im Browser, alle Daten bleiben lokal (localStorage), kein Login, kein Server. Kann auf Mobilgeräten und Desktop-Browsern über "Zum Startbildschirm hinzufügen" bzw. "Installieren" als eigenständige App eingerichtet werden (PWA mit Offline-Unterstützung).

Eigenständig und unabhängig vom Immobilien-Rechner im Repo-Root – keine geteilten Dateien oder Daten.
